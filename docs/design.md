# 视觉方向：纸面备忘录

2026-09-29 从两套方向中选定 A「纸面备忘录」，并吸收 B「决策工作台」的权重滑块。两套对比稿存档在 [design-directions.html](design-directions.html)，可以直接用浏览器打开。

## 为什么选它

- 主线主要用来低频地想清楚方向，不是每天高频操作的工具。备忘录式的单页阅读更合适：先写结论，再给依据。
- 符合 AGENTS.md 的原则“用字号、字重与留白建立层级，避免重复标题和装饰”：不用卡片，只用细线分隔。
- 保留 B 的权重滑块：调权重时，各维度的占比和加权分即时变化。

## 规则

- **一个强调色。** `lead`（朱红）只用于领先项、翻盘关键和错误提示，不做装饰。
- **两种字体分工。** 宋体（`font-serif`）写“内容”：结论、选项、维度、阶段主线、信号。苹方（`font-sans`）写“说明”：注释、按钮、表头、任务。数字统一用 `font-num` 并开启 `tabular-nums`。
- **四级墨色。** `ink` 正文，`ink-2` 次要，`ink-3` 注释（对纸色对比度 ≥ 4.5:1），`ink-4` 只用于占位、禁用和空分数，不承载必须读到的信息。
- **分隔用线。** 行与行之间用 1px `rule`，结论区上方用 2px `rule-strong`。展开的编辑区用 `lead-soft` 浅底色，与普通行区分开。
- **交互保持克制。** “添加”只是一行“＋ …”输入；按钮都是文字按钮；焦点统一显示朱红描边。
- **先定权重再打分。** 权重锁定前不能打分，锁定后不能调权重；这条由 Server Action 在服务端强制，不只是界面限制。

## 参考与借鉴点

没有照搬任何产品的品牌或截图，只借鉴以下特点：

- 瑞士国际主义版式：栅格与粗细线的节奏。
- Edward Tufte 的数据墨水比：让数字本身成为图。
- 日式新书排版：宽松的行距和克制的用色。
- Material Design：状态、焦点和语义的清晰度（用于部件状态，不引入 MUI）。
